# rohit-web

Source of https://rohit.niwav.in, Rohit's personal site: travel, writing and notes.
Static site (Astro), deployed to GitHub Pages on every merge to `main`.

This repository is public. Read `CLAUDE.md` (rules and privacy gates) and
`SOURCES.md` (who may publish what) before adding content.

```
npm ci
npm run dev           # local preview
npm run build         # static site in dist/
npm run check:public  # privacy gate (needs exiftool)
```
